Object & data shaping · Problem 03

Deep Merge Two Objects

The recursion is six lines. Everything interesting is a policy decision: what happens when both sides have an array? What about undefined? And a merge that walks user input into an object has the same __proto__ vulnerability as the last page.

The one-line definition

A deep merge takes the union of the keys. Where both sides have a plain object, it merges them recursively. Where they do not, the later source wins.

Everything else on this page is deciding what “where they do not” should mean.

Version 0b — the six-line answer
const isPlain = (v) =>
  v !== null && typeof v === 'object' && v.constructor === Object;

function deepMerge(target, source) {
  const out = { ...target };
  for (const [key, value] of Object.entries(source)) {
    out[key] = isPlain(value) && isPlain(out[key])
      ? deepMerge(out[key], value)          // both plain objects -> recurse
      : value;                              // otherwise the source wins
  }
  return out;
}

Think first — the array question

There is no correct answer. There are four defensible answers, and the interviewer wants to hear that you know it is a choice.

Strategy[1,2] + [3]Right for
replace[3]config lists — the user means “exactly these”
concat[1,2,3]plugin lists, middleware, additive settings
union[1,2,3] dedupedtags, permissions, feature flags
by index[3,2]fixed-length tuples; almost never otherwise
all four, on the same input
const isPlain = (v) => v !== null && typeof v === 'object' && v.constructor === Object;

function merge(target, source, arrayStrategy) {
  const out = Array.isArray(target) ? [...target] : { ...target };

  for (const [key, value] of Object.entries(source)) {
    const existing = out[key];

    if (isPlain(value) && isPlain(existing)) {
      out[key] = merge(existing, value, arrayStrategy);
    } else if (Array.isArray(value) && Array.isArray(existing)) {
      out[key] = arrayStrategy(existing, value);
    } else {
      out[key] = value;
    }
  }

  return out;
}

const strategies = {
  replace: (a, b) => b,
  concat: (a, b) => [...a, ...b],

    const out = [...a];
    b.forEach((v, i) => { out[i] = v; });
    return out;

};

const isPlain = (v) => v !== null && typeof v === 'object' && v.constructor === Object;

// (a) immutable: a new object at every level
function mergeImmutable(target, source) {
  const out = { ...target };
  for (const [k, v] of Object.entries(source)) {
    out[k] = isPlain(v) && isPlain(out[k]) ? mergeImmutable(out[k], v) : v;
  }
  return out;
}

// (b) mutating a fresh deep copy: one copy, then write in place
function deepCopy(v) {
  if (!isPlain(v) && !Array.isArray(v)) return v;
  if (Array.isArray(v)) return v.map(deepCopy);
  const out = {};
  for (const k of Object.keys(v)) out[k] = deepCopy(v[k]);
  return out;
}
function mergeIntoCopy(target, source) {
  const out = deepCopy(target);
  (function walk(dst, src) {
    for (const [k, v] of Object.entries(src)) {
      if (isPlain(v) && isPlain(dst[k])) walk(dst[k], v);
      else dst[k] = deepCopy(v);
    }
  })(out, source);
  return out;
}

}

Step 4

The better idea — the five decisions

  merge(target, source):

      out = a shallow copy of target

      for each [key, value] in source:

          1. is `key` dangerous?          __proto__ / constructor /
                                          prototype  ->  skip
          2. both sides PLAIN OBJECTS?    ->  recurse
          3. both sides ARRAYS?           ->  the array strategy
          4. value is undefined?          ->  skip, or overwrite?
          5. otherwise                    ->  out[key] = value

      return out


  The order matters. The prototype check must be FIRST, before
  anything reads or writes out[key].
The two policies to state out loud

Arrays: replace by default. It is the least surprising, and it is what “the user's config wins” means. Make it configurable.

undefined: skip it by default, so merge(defaults, { port: undefined }) keeps the default. That matches how default parameters behave, and it means a partial object built with optional fields does not wipe things out. But it also means you cannot unset a value — and that trade is worth mentioning.

Version 1 — for...in, hasOwnProperty, manual copying
function isPlainObject(v) {
  return v !== null && typeof v === 'object' &&
         Object.prototype.toString.call(v) === '[object Object]';
}

function shallowCopy(obj) {
  const out = {};
  for (const k in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, k)) out[k] = obj[k];
  }
  return out;
}

const FORBIDDEN = { __proto__: true, constructor: true, prototype: true };

function deepMergeManual(target, source) {
  const out = shallowCopy(target);

  for (const key in source) {
    if (!Object.prototype.hasOwnProperty.call(source, key)) continue;
    // the guard comes FIRST, before any read or write of out[key]
    if (Object.prototype.hasOwnProperty.call(FORBIDDEN, key)) continue;

    const value = source[key];
    if (value === undefined) continue;

    if (isPlainObject(value) && isPlainObject(out[key])) {
      out[key] = deepMergeManual(out[key], value);
    } else {
      out[key] = value;
    }
  }

  return out;
}

// variadic: merge many sources left to right
function mergeAll() {
  let result = {};
  for (let i = 0; i < arguments.length; i++) {
    result = deepMergeManual(result, arguments[i]);
  }
  return result;
}

const isPlain = (v) =>
  v !== null && typeof v === 'object' &&
  (v.constructor === Object || v.constructor === undefined);

const FORBIDDEN = new Set(['__proto__', 'constructor', 'prototype']);

const ARRAY_STRATEGIES = {
  replace: (a, b) => b,
  concat: (a, b) => [...a, ...b],
  union: (a, b) => [...new Set([...a, ...b])],
};

function deepMerge(...sources) {
  const options = { arrays: 'replace', skipUndefined: true };
  // an options object may be passed last, marked so it is unambiguous
  const last = sources[sources.length - 1];
  if (last && last.__mergeOptions) {
    Object.assign(options, sources.pop().__mergeOptions);
  }

  const combineArrays = typeof options.arrays === 'function'
    ? options.arrays
    : ARRAY_STRATEGIES[options.arrays];

  function two(target, source) {
    const out = { ...target };

    for (const key of Object.keys(source)) {
      if (FORBIDDEN.has(key)) continue;

      const value = source[key];
      if (value === undefined && options.skipUndefined) continue;

      const existing = out[key];

      if (isPlain(value) && isPlain(existing)) out[key] = two(existing, value);
      else if (Array.isArray(value) && Array.isArray(existing)) {
        out[key] = combineArrays(existing, value);
      } else out[key] = value;
    }

    return out;
  }

  return sources.reduce((acc, src) => two(acc, src ?? {}), {});
}

a merge that does NOT share structure
const isPlain = (v) => v !== null && typeof v === 'object' && v.constructor === Object;

// the sharing version -- fast, and the result aliases the inputs
function mergeSharing(target, source) {
  const out = { ...target };
  for (const [k, v] of Object.entries(source)) {
    out[k] = isPlain(v) && isPlain(out[k]) ? mergeSharing(out[k], v) : v;
  }
  return out;
}

// the isolating version -- every value deep-copied on the way in
function deepCopy(v, seen = new Map()) {
  if (v === null || typeof v !== 'object') return v;
  if (seen.has(v)) return seen.get(v);
  if (v instanceof Date) return new Date(v.getTime());
  const out = Array.isArray(v) ? [] : {};
  seen.set(v, out);
  for (const k of Object.keys(v)) out[k] = deepCopy(v[k], seen);
  return out;
}
function mergeIsolating(target, source) {
  const out = {};
  for (const k of Object.keys(target)) out[k] = deepCopy(target[k]);
  for (const [k, v] of Object.entries(source)) {
    out[k] = isPlain(v) && isPlain(out[k]) ? mergeIsolating(out[k], v) : deepCopy(v);
  }
  return out;
}

merge via flatten, and structuredClone
// A completely different implementation: flatten both, overlay the
// paths, unflatten. Short, and it inherits every flatten limitation.
const isPlain = (v) => v !== null && typeof v === 'object' && v.constructor === Object;

function flatten(obj, prefix = '', out = {}) {
  for (const [k, v] of Object.entries(obj)) {
    const path = prefix ? prefix + '' + k : k;
    if (isPlain(v) && Object.keys(v).length > 0) flatten(v, path, out);
    else out[path] = v;
  }
  return out;
}
function unflatten(flat) {
  const out = {};
  for (const [path, v] of Object.entries(flat)) {
    const parts = path.split('');
    let node = out;
    for (let i = 0; i < parts.length - 1; i++) {
      if (!isPlain(node[parts[i]])) node[parts[i]] = {};
      node = node[parts[i]];
    }
    node[parts[parts.length - 1]] = v;
  }
  return out;
}

                   retries: 3 };

function deepMerge(t, s) {
  const out = { ...t };
  for (const [k, v] of Object.entries(s)) {
    out[k] = isPlain(v) && isPlain(out[k]) ? deepMerge(out[k], v) : v;
  }
  return out;
}

Step 8

Complexity, in sentences

ApproachTimeAllocated
recursive, structural sharingO(s + ttop)one object per level touched
recursive, isolatingO(s + t)a full copy of both
via flatten / unflattenO((s + t) · d)two flat objects plus path strings

s is the size of the source, t the size of the target. The sharing version is the interesting one: it copies only the top level of the target plus each level the source actually descends into. A one-key override of a huge config touches a handful of objects, not the whole tree — which is why Step 3's measurement came out the way it did.

The isolating version is O(s + t) because it copies everything, and that is the price of not aliasing the inputs.

Say this in the interview

“Shallow-copy the target, then walk the source's keys: where both sides have a plain object I recurse, otherwise the source wins. The three things to raise before being asked are policies, not code. Arrays: I replace by default, because that is what a config override means, but concat and union are both reasonable and lodash actually merges by index, which surprises people. undefined: I skip it, so a partially-filled options object does not wipe defaults, but null I treat as an explicit value. And the result shares structure with the inputs, so if the target is a defaults object reused across requests I clone first — otherwise one request's mutation leaks into every later one. Also, any merge that walks keys from a request body has to reject __proto__.”

// lodash-style: arrays merged BY INDEX
function mergeByIndex(target, source) {
  const out = Array.isArray(target) ? [...target] : { ...target };
  for (const [k, v] of Object.entries(source)) {
    const existing = out[k];
    if ((isPlain(v) && isPlain(existing)) ||
        (Array.isArray(v) && Array.isArray(existing))) {
      out[k] = mergeByIndex(existing, v);

  }
  return out;
}

Step 10

Practice before you move on

  1. Write the six-line version from memory, then say the array policy and the undefined policy before you are asked.
  2. Add the __proto__ guard and be able to name all three forbidden keys and why constructor is one of them.
  3. Make it variadic. Step 6 — mergeAll(a, b, c), left to right.
  4. Write the isolating version. Step 7 — and explain the reused-defaults bug it prevents.
  5. Deep equality. The next page — same recursion, mirror problem, and a different set of traps.
What to carry forward

Three lines of recursion, and three policies. The code is easy; what makes a merge correct or wrong is what you decided about arrays, about undefined, and about whether the result may alias its inputs. Say all three out loud, because a merge whose behaviour the caller has to discover by experiment is a bug generator — and add the __proto__ guard the moment any of those keys come from a request.
