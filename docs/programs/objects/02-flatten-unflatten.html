Object & data shaping · Problem 02

Flatten & Unflatten Dot-Notation Objects

Both directions are short recursions. The reason this is a good interview question is the follow-up almost nobody survives: the round trip is not lossless, and there are four separate reasons why.

Step 1

The problem

both directions
flatten({ a: 1, b: { c: 2, d: { e: 3 } } })
  ->  { 'a': 1, 'b.c': 2, 'b.d.e': 3 }

unflatten({ 'a': 1, 'b.c': 2, 'b.d.e': 3 })
  ->  { a: 1, b: { c: 2, d: { e: 3 } } }

Where you actually meet it: form libraries (a field named address.city), query strings, environment variables (DB__HOST), MongoDB update documents ({ $set: { 'address.city': 'London' } }), translation files, and any config system that has to represent a tree in a flat key-value store.

Version 0 — both directions, eight lines each
function flatten(obj, prefix = '') {
  const out = {};
  for (const [key, value] of Object.entries(obj)) {
    const path = prefix ? prefix + '.' + key : key;
    if (value !== null && typeof value === 'object' && !Array.isArray(value)) {
      Object.assign(out, flatten(value, path));
    } else {
      out[path] = value;
    }
  }
  return out;
}

function unflatten(flat) {
  const out = {};
  for (const [path, value] of Object.entries(flat)) {
    const parts = path.split('.');
    let node = out;
    for (let i = 0; i < parts.length - 1; i++) {
      node[parts[i]] ??= {};                  // create the level if missing
      node = node[parts[i]];
    }
    node[parts[parts.length - 1]] = value;
  }
  return out;
}

The honest answer to give

“A dot-notation flatten is lossy, and here are the four cases.” Then say what you would do about each: keep a marker for empty containers, escape or forbid dots in keys, decide explicitly whether arrays are leaves or are traversed with bracket notation, and record whether each level was an array.

Most real libraries pick a subset and document it. Saying that is a better answer than pretending it round-trips.

Step 3

Why the naive merge is slow

Object.assign(out, flatten(child, path)) builds a whole intermediate object per level and copies it into the parent. It is the concat-in-a-reduce mistake again.

Timing demo — merge per level versus one accumulator
// build something deep and wide
function build(depth, width) {
  if (depth === 0) return 1;
  const node = {};
  for (let i = 0; i < width; i++) node['k' + i] = build(depth - 1, width);
  return node;
}
const data = build(6, 6);          // 6^6 = 46,656 leaves

// (a) a new object per level, merged upward
function flattenMerge(obj, prefix = '') {
  const out = {};
  for (const [k, v] of Object.entries(obj)) {
    const path = prefix ? prefix + '.' + k : k;
    if (v !== null && typeof v === 'object' && !Array.isArray(v)) {
      Object.assign(out, flattenMerge(v, path));
    } else {
      out[path] = v;
    }
  }
  return out;
}

// (b) one shared accumulator, written into directly
function flattenAccumulate(obj) {
  const out = {};
  (function walk(node, prefix) {
    for (const [k, v] of Object.entries(node)) {
      const path = prefix ? prefix + '.' + k : k;
      if (v !== null && typeof v === 'object' && !Array.isArray(v)) walk(v, path);
      else out[path] = v;
    }
  })(obj, '');
  return out;
}

Step 4

The better idea — decide the four questions first

QuestionOptions
Are arrays leaves?keep whole · index into them with .0 · index with [0]
What about empty containers?drop them · keep a marker ({} / [] as the value)
Can keys contain the separator?forbid · escape · use a separator that cannot occur
How deep?unlimited · a maxDepth, keeping deeper values whole
 
  flatten(obj, prefix, out):

      for each [key, value]:

          path = prefix ? prefix + SEP + key : key

          value is a plain object or array, and NOT empty
              ->  recurse with path

          value is an EMPTY object or array
              ->  out[path] = value        (the marker)

          anything else (including Date, Map, null)
              ->  out[path] = value


  unflatten(flat):

      for each [path, value]:

          parts = split(path)

          walk down, creating each missing level.
          Decide the container from the NEXT part:
              next part is all digits  ->  create []
              otherwise                ->  create {}

      That last rule is what makes arrays come back as arrays.
The numeric-key rule cuts both ways

Auto-creating an array when the next segment is numeric makes tags.0 come back as an array — which is usually right. But it also turns { counts: { 5: 'x' } } into an array with five empty slots. There is no way to have both without recording the container type; pick one and document it.

function flattenLoud(obj) {
  const out = {};
  (function walk(node, prefix, depth) {
    const pad = '  '.repeat(depth);
    for (const [key, value] of Object.entries(node)) {
      const path = prefix ? prefix + '.' + key : key;
      const isPlain = value !== null && typeof value === 'object' && !Array.isArray(value);
      if (isPlain) {
        console.log(pad + key + ' -> object, recursing with prefix "' + path + '"');
        walk(value, path, depth + 1);
      } else {
        out[path] = value;
        console.log(pad + key + ' -> leaf, out["' + path + '"] = ' + JSON.stringify(value));
      }
    }
  })(obj, '', 0);
  return out;
}

Version 1 — for...in with hasOwnProperty, manual splitting
function isPlainObject(v) {
  return v !== null && typeof v === 'object' &&
         Object.prototype.toString.call(v) === '[object Object]';
}

function splitManual(str, sep) {
  const parts = [];
  let current = '';
  for (let i = 0; i < str.length; i++) {
    if (str[i] === sep) { parts[parts.length] = current; current = ''; }
    else current = current + str[i];
  }
  parts[parts.length] = current;
  return parts;
}

function flattenManual(obj) {
  const out = {};

  function walk(node, prefix) {
    for (const key in node) {
      if (!Object.prototype.hasOwnProperty.call(node, key)) continue;
      const value = node[key];
      const path = prefix === '' ? key : prefix + '.' + key;
      if (isPlainObject(value)) walk(value, path);
      else out[path] = value;
    }
  }

  walk(obj, '');
  return out;
}

function unflattenManual(flat) {
  const out = {};
  for (const path in flat) {
    if (!Object.prototype.hasOwnProperty.call(flat, path)) continue;
    const parts = splitManual(path, '.');
    let node = out;
    for (let i = 0; i < parts.length - 1; i++) {
      if (node[parts[i]] === undefined) node[parts[i]] = {};
      node = node[parts[i]];
    }
    node[parts[parts.length - 1]] = flat[path];
  }
  return out;
}

Version 2 — the interview answer
const isPlain = (v) =>
  v !== null && typeof v === 'object' && v.constructor === Object;

function flatten(obj, options = {}) {
  const {
    separator = '.',
    flattenArrays = true,       // index into arrays, or keep them whole
    keepEmpty = true,           // emit {} and [] as markers
    maxDepth = Infinity,
  } = options;

  const out = {};

  (function walk(node, prefix, depth) {
    const entries = Array.isArray(node)
      ? node.map((v, i) => [String(i), v])
      : Object.entries(node);

    // an empty container has no entries, so record it explicitly
    if (entries.length === 0 && prefix !== '') {
      if (keepEmpty) out[prefix] = Array.isArray(node) ? [] : {};
      return;
    }

    for (const [key, value] of entries) {
      const path = prefix ? prefix + separator + key : key;
      const traversable = isPlain(value) || (flattenArrays && Array.isArray(value));

      if (traversable && depth < maxDepth) walk(value, path, depth + 1);
      else out[path] = value;
    }
  })(obj, '', 0);

  return out;
}

function unflatten(flat, options = {}) {
  const { separator = '.', makeArrays = true } = options;
  const out = {};

  for (const [path, value] of Object.entries(flat)) {
    const parts = path.split(separator);
    let node = out;

    for (let i = 0; i < parts.length - 1; i++) {
      const key = parts[i];
      if (node[key] === undefined || typeof node[key] !== 'object') {
        // the NEXT part decides whether this level is an array
        const nextIsIndex = makeArrays && /^\d+$/.test(parts[i + 1]);
        node[key] = nextIsIndex ? [] : {};
      }
      node = node[key];
    }

    node[parts[parts.length - 1]] = value;
  }

  return out;
}

get, set and has by path — the useful cousins
// You usually do not want the whole flat object. You want ONE path.
function getPath(obj, path, fallback) {
  const parts = Array.isArray(path) ? path : String(path).split('.');
  let node = obj;
  for (const key of parts) {
    if (node === null || node === undefined) return fallback;
    node = node[key];
  }
  return node === undefined ? fallback : node;
}

function setPath(obj, path, value) {
  const parts = Array.isArray(path) ? path : String(path).split('.');
  let node = obj;
  for (let i = 0; i < parts.length - 1; i++) {
    const key = parts[i];
    if (node[key] === null || typeof node[key] !== 'object') {
      node[key] = /^\d+$/.test(parts[i + 1]) ? [] : {};
    }
    node = node[key];
  }
  node[parts[parts.length - 1]] = value;
  return obj;
}

function hasPath(obj, path) {
  const parts = Array.isArray(path) ? path : String(path).split('.');
  let node = obj;
  for (const key of parts) {
    if (node === null || typeof node !== 'object' || !(key in node)) return false;
    node = node[key];
  }
  return true;
}

bracket notation, and the escaping question
// Form libraries and query strings usually use brackets for array
// indexes: "items[0].sku". Parsing that is a small tokenizer.
function parsePath(path) {
  const parts = [];
  let current = '';
  let i = 0;

  while (i < path.length) {
    const ch = path[i];

    if (ch === '.') {
      if (current !== '') { parts.push(current); current = ''; }
      i++;
    } else if (ch === '[') {
      if (current !== '') { parts.push(current); current = ''; }
      const close = path.indexOf(']', i);
      if (close === -1) throw new Error('unterminated [ in ' + JSON.stringify(path));
      let inner = path.slice(i + 1, close);
      // strip quotes: a['weird.key'] keeps the dot
      if (/^['"].*['"]$/.test(inner)) inner = inner.slice(1, -1);
      parts.push(inner);
      i = close + 1;
    } else {
      current += ch;
      i++;
    }
  }
  if (current !== '') parts.push(current);
  return parts;
}

Step 8

Complexity, in sentences

OperationTimeSpace
flatten, one accumulatorO(n)O(n) output, O(d) stack
flatten, merging per levelO(n · d)O(n · d) allocated
unflattenO(n · d)O(n)
getPathO(d)O(1)

n is the number of leaves, d the maximum depth. Flatten is linear with a shared accumulator. Unflatten is O(n · d) because each path is split and walked — there is no avoiding that, and d is small.

The hidden cost is string building. Every leaf's path is a fresh string, and the path for a leaf at depth d concatenates d segments. For a large configuration tree the flat form is often several times the memory of the nested one, entirely in key strings.

Say this in the interview

“Flatten is one recursion carrying the prefix down and writing into a single shared accumulator — not merging a new object per level, which would make it O(n·d). Unflatten splits each path and walks down creating missing levels, using the next segment to decide whether a level should be an object or an array. The important thing to say up front is that the round trip is lossy: empty objects and arrays disappear because they contribute no keys, a key containing a dot becomes indistinguishable from a nested path, and a numeric key is ambiguous between an object key and an array index. In practice I would use bracket notation for indexes and quoted brackets for keys containing the separator.”

// tests for a plain object specifically
const isPlain = (v) => v !== null && typeof v === 'object' && v.constructor === Object;
function flattenSafe(obj) {
  const out = {};

    for (const [k, v] of Object.entries(node)) {
      const path = prefix ? prefix + '.' + k : k;
      if (isPlain(v) || Array.isArray(v)) walk(v, path);
      else out[path] = v;

}

const FORBIDDEN = new Set(['__proto__', 'constructor', 'prototype']);
function unflattenSafe(flat) {
  const out = Object.create(null);
  for (const [path, value] of Object.entries(flat)) {
    const parts = path.split('.');
    if (parts.some((p) => FORBIDDEN.has(p))) continue;      // or throw

    for (let i = 0; i < parts.length - 1; i++) {
      if (node[parts[i]] === undefined) node[parts[i]] = Object.create(null);
      node = node[parts[i]];
    }
    node[parts[parts.length - 1]] = value;
  }
  return out;
}

function unflattenStrict(flat) {
  const out = {};
  const leaves = new Set();
  for (const [path, value] of Object.entries(flat)) {
    const parts = path.split('.');
    let node = out;
    let sofar = '';
    for (let i = 0; i < parts.length - 1; i++) {
      sofar = sofar ? sofar + '.' + parts[i] : parts[i];
      if (leaves.has(sofar)) {
        throw new Error('"' + sofar + '" is both a value and a branch');
      }
      if (node[parts[i]] === undefined) node[parts[i]] = {};
      node = node[parts[i]];
    }
    const last = parts[parts.length - 1];
    const fullPath = sofar ? sofar + '.' + last : last;
    if (node[last] !== undefined && typeof node[last] === 'object') {
      throw new Error('"' + fullPath + '" is both a value and a branch');
    }
    leaves.add(fullPath);
    node[last] = value;
  }
  return out;
}

5. Assuming numeric keys mean arrays — or that they never do

two defensible choices, both wrong sometimes
function unflatten(flat, makeArrays) {
  const out = {};
  for (const [path, value] of Object.entries(flat)) {
    const parts = path.split('.');
    let node = out;
    for (let i = 0; i < parts.length - 1; i++) {
      if (node[parts[i]] === undefined) {
        node[parts[i]] = makeArrays && /^\d+$/.test(parts[i + 1]) ? [] : {};
      }
      node = node[parts[i]];
    }
    node[parts[parts.length - 1]] = value;
  }
  return out;
}

Step 10

Practice before you move on

  1. Write both directions from memory. Then state the four losses without being prompted — empties, dots in keys, arrays, numeric keys.
  2. Write getPath and setPath. Step 7 — in real code you reach for these far more often than for a full flatten.
  3. Handle the __proto__ payload. Step 9 — and be able to name all three forbidden segments.
  4. Write the bracket-notation parser. Step 7's last block. It is a tiny tokenizer and it comes up in form libraries constantly.
  5. Deep merge. The next page — and once you have setPath, one way to write a deep merge is to flatten both objects and set every path.
What to carry forward

A flat representation of a tree loses information, and you should say which. Empty containers vanish, separators collide with data, and container types become guesses. The good engineering answer is not a cleverer heuristic — it is to put the ambiguity in the format (brackets, quoting, a separator that cannot occur) so it stops being a guess. And any code that turns strings into object paths must reject __proto__.
