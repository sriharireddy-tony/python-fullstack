Object & data shaping · Problem 04

Deep Equality Check

The mirror of deep clone: the same shape recursion, the same cycle problem, and a completely different set of traps. JSON.stringify(a) === JSON.stringify(b) is the wrong answer for six separate reasons, and being able to list them is most of the question.

Step 1

The problem

Decide whether two values are “the same” by structure rather than by identity.

Three different notions of “equal”

== — loose, with coercion. '1' == 1, null == undefined. Never what you want here.

=== — strict, no coercion, identity for objects. Two exceptions: NaN and -0.

Object.is — SameValue: like === but NaN equals itself and 0 does not equal -0.

A deep equal is a fourth thing built on top: recurse into structure, compare leaves with one of the above.

Step 4

The better idea — the checks in order

  deepEqual(a, b, seen):

   1. a === b                      ->  true
      (fast path: same object, or equal primitives)

   2. either is null, or either is not an object
      ->  they are primitives, and step 1 already said no.
          The only remaining true case is NaN vs NaN.

   3. different prototypes          ->  false
      (an array is not a plain object; a Dog is not a Cat)

   4. already comparing this pair?  ->  true
      (the cycle guard: assume equal, let the rest decide)

   5. the built-ins that need their own comparison:
          Date      getTime()
          RegExp    source and flags
          Map       same size, every key present with an equal value
          Set       same size, every member present
          typed arrays / ArrayBuffer   byte by byte

   6. arrays        same length, every index deep-equal

   7. plain objects  same key COUNT, and every key of `a` present
                     in `b` with a deep-equal value

  Order matters. Step 1 before anything (it is the common case),
  step 3 before step 5 (so a Date is never compared to an object),
  step 4 before any recursion (or a cycle never terminates).
Why step 2 reduces to a NaN check

If a === b was false and neither is an object, they are two different primitives — with exactly one exception, because NaN !== NaN. So the whole primitive branch is Number.isNaN(a) && Number.isNaN(b).

Note this makes deepEqual(0, -0) true, because 0 === -0. That is almost always what you want structurally — but say it out loud, because Object.is disagrees.

the key-count check, and why it is not enough on its own
// comparing only a's keys, without checking the count
function missingCountCheck(a, b) {
  if (a === b) return true;
  if (typeof a !== 'object' || typeof b !== 'object' || !a || !b) return false;
  for (const k of Object.keys(a)) {
    if (!missingCountCheck(a[k], b[k])) return false;
  }
  return true;                           // b may have EXTRA keys
}

// comparing counts but using undefined for missing keys
function countOnly(a, b) {
  if (a === b) return true;
  if (typeof a !== 'object' || typeof b !== 'object' || !a || !b) return false;
  const ka = Object.keys(a), kb = Object.keys(b);
  if (ka.length !== kb.length) return false;
  for (const k of ka) if (!countOnly(a[k], b[k])) return false;
  return true;
}

// counts AND membership
function correct(a, b) {
  if (a === b) return true;
  if (typeof a !== 'object' || typeof b !== 'object' || !a || !b) {
    return Number.isNaN(a) && Number.isNaN(b);
  }
  const ka = Object.keys(a), kb = Object.keys(b);
  if (ka.length !== kb.length) return false;
  for (const k of ka) {
    if (!Object.prototype.hasOwnProperty.call(b, k)) return false;
    if (!correct(a[k], b[k])) return false;
  }
  return true;
}

Step 5

Dry run — the cycle case

  const a = { name: 'a' };  a.self = a;
  const b = { name: 'a' };  b.self = b;

  deepEqual(a, b, seen = new Map())

    a !== b
    both objects, same prototype
    seen does not have a -> record  seen: { a -> b }

    key 'name'  ->  deepEqual('a', 'a')  ->  true

    key 'self'  ->  deepEqual(a.self, b.self)  =  deepEqual(a, b)
                    seen HAS a, and seen.get(a) === b
                    ->  true            <-- recursion stops here

    all keys equal  ->  true


  Why "assume true" is correct:

  If the two graphs really differ, some OTHER comparison will
  find it -- the cycle guard only says "we are already checking
  this pair, do not go round again". Assuming false would make
  two identical cyclic structures compare unequal.

function deepEqualLoud(a, b, seen = new Map(), path = 'root', depth = 0) {
  const pad = '  '.repeat(depth);
  const show = (v) => (typeof v === 'object' && v !== null ? '{...}' : JSON.stringify(v));

  console.log(pad + path + ': ' + show(a) + ' vs ' + show(b));

  if (a === b) { console.log(pad + '  === -> true'); return true; }

  if (a === null || b === null || typeof a !== 'object' || typeof b !== 'object') {
    const both = Number.isNaN(a) && Number.isNaN(b);
    console.log(pad + '  primitives, not === -> ' + both +
                (both ? ' (both NaN)' : ''));
    return both;
  }

  if (seen.has(a)) {
    const known = seen.get(a) === b;
    console.log(pad + '  ALREADY COMPARING this pair -> ' + known);
    return known;
  }
  seen.set(a, b);
  console.log(pad + '  recorded the pair, descending');

  const ka = Object.keys(a), kb = Object.keys(b);
  if (ka.length !== kb.length) {
    console.log(pad + '  key counts differ (' + ka.length + ' vs ' + kb.length + ') -> false');
    return false;
  }

  for (const k of ka) {
    if (!Object.prototype.hasOwnProperty.call(b, k)) {
      console.log(pad + '  b has no key "' + k + '" -> false');
      return false;
    }
    if (!deepEqualLoud(a[k], b[k], seen, k, depth + 1)) return false;
  }

  console.log(pad + '  all keys matched -> true');
  return true;
}

function deepEqualBasic(a, b) {
  // 1. identical, or equal primitives
  if (a === b) return true;

  // 2. primitives that are not ===: only NaN survives
  if (a === null || b === null ||
      typeof a !== 'object' || typeof b !== 'object') {
    return a !== a && b !== b;              // the classic NaN test
  }

  // 3. one array, one object
  const aIsArray = Object.prototype.toString.call(a) === '[object Array]';
  const bIsArray = Object.prototype.toString.call(b) === '[object Array]';
  if (aIsArray !== bIsArray) return false;

  if (aIsArray) {
    if (a.length !== b.length) return false;
    for (let i = 0; i < a.length; i++) {
      if (!deepEqualBasic(a[i], b[i])) return false;
    }
    return true;
  }

  // 4. plain objects: same key count, every key present and equal
  let countA = 0;
  for (const k in a) {
    if (!Object.prototype.hasOwnProperty.call(a, k)) continue;
    countA++;
    if (!Object.prototype.hasOwnProperty.call(b, k)) return false;
    if (!deepEqualBasic(a[k], b[k])) return false;
  }

  let countB = 0;
  for (const k in b) {
    if (Object.prototype.hasOwnProperty.call(b, k)) countB++;
  }

  return countA === countB;
}

function deepEqual(a, b, seen = new Map()) {
  // 1. fast path
  if (a === b) return true;

  // 2. primitives
  if (a === null || b === null ||
      typeof a !== 'object' || typeof b !== 'object') {
    return Number.isNaN(a) && Number.isNaN(b);
  }

  // 3. same kind of thing?
  if (Object.getPrototypeOf(a) !== Object.getPrototypeOf(b)) return false;

  // 4. cycle guard, BEFORE any recursion
  if (seen.get(a) === b) return true;
  seen.set(a, b);

  // 5. the built-ins
  if (a instanceof Date) return a.getTime() === b.getTime() ||
                                (Number.isNaN(a.getTime()) && Number.isNaN(b.getTime()));
  if (a instanceof RegExp) return a.source === b.source && a.flags === b.flags;

  if (a instanceof Map) {
    if (a.size !== b.size) return false;
    for (const [key, value] of a) {
      // an object key needs a structural search, not a lookup
      if (key !== null && typeof key === 'object') {
        let found = false;
        for (const [k2, v2] of b) {
          if (deepEqual(key, k2, seen) && deepEqual(value, v2, seen)) { found = true; break; }
        }
        if (!found) return false;
      } else {
        if (!b.has(key)) return false;
        if (!deepEqual(value, b.get(key), seen)) return false;
      }
    }
    return true;
  }

  if (a instanceof Set) {
    if (a.size !== b.size) return false;
    for (const value of a) {
      if (b.has(value)) continue;
      if (value === null || typeof value !== 'object') return false;
      let found = false;
      for (const other of b) if (deepEqual(value, other, seen)) { found = true; break; }
      if (!found) return false;
    }
    return true;
  }

  if (ArrayBuffer.isView(a) && !(a instanceof DataView)) {
    if (a.length !== b.length) return false;
    for (let i = 0; i < a.length; i++) if (a[i] !== b[i]) return false;
    return true;
  }

  // 6. arrays
  if (Array.isArray(a)) {
    if (a.length !== b.length) return false;
    for (let i = 0; i < a.length; i++) {
      if (!deepEqual(a[i], b[i], seen)) return false;
    }
    return true;
  }

  // 7. plain objects and class instances
  const ka = Reflect.ownKeys(a).filter((k) =>
    Object.getOwnPropertyDescriptor(a, k).enumerable);
  const kb = Reflect.ownKeys(b).filter((k) =>
    Object.getOwnPropertyDescriptor(b, k).enumerable);
  if (ka.length !== kb.length) return false;

  for (const key of ka) {
    if (!Object.prototype.hasOwnProperty.call(b, key)) return false;
    if (!deepEqual(a[key], b[key], seen)) return false;
  }

  return true;
}

function deepEqual(a, b, seen = new Map()) {
  if (a === b) return true;
  if (a === null || b === null || typeof a !== 'object' || typeof b !== 'object') {
    return Number.isNaN(a) && Number.isNaN(b);
  }
  if (Object.getPrototypeOf(a) !== Object.getPrototypeOf(b)) return false;
  if (seen.get(a) === b) return true;
  seen.set(a, b);
  if (a instanceof Date) return a.getTime() === b.getTime();
  if (Array.isArray(a)) {
    if (a.length !== b.length) return false;
    return a.every((v, i) => deepEqual(v, b[i], seen));
  }
  const ka = Object.keys(a), kb = Object.keys(b);
  if (ka.length !== kb.length) return false;
  return ka.every((k) =>
    Object.prototype.hasOwnProperty.call(b, k) && deepEqual(a[k], b[k], seen));

// 1. WHERE do they differ? Far more useful than a boolean.
function deepDiff(a, b, path = '') {
  const diffs = [];

  (function walk(x, y, p) {
    if (deepEqual(x, y)) return;

    const bothPlain = x !== null && y !== null &&
      typeof x === 'object' && typeof y === 'object' &&
      Array.isArray(x) === Array.isArray(y) &&
      !(x instanceof Date) && !(y instanceof Date);

    if (!bothPlain) { diffs.push({ path: p || 'root', a: x, b: y }); return; }

    const keys = new Set([...Object.keys(x), ...Object.keys(y)]);
    for (const k of keys) {
      const next = p ? p + '.' + k : k;
      const inA = Object.prototype.hasOwnProperty.call(x, k);
      const inB = Object.prototype.hasOwnProperty.call(y, k);
      if (!inA) diffs.push({ path: next, a: '(missing)', b: y[k] });
      else if (!inB) diffs.push({ path: next, a: x[k], b: '(missing)' });
      else walk(x[k], y[k], next);
    }
  })(a, b, path);

  return diffs;
}

// 2. a SHALLOW equal -- what React uses for props
function shallowEqual(a, b) {
  if (a === b) return true;
  if (!a || !b || typeof a !== 'object' || typeof b !== 'object') return false;
  const ka = Object.keys(a), kb = Object.keys(b);
  if (ka.length !== kb.length) return false;
  return ka.every((k) => Object.prototype.hasOwnProperty.call(b, k) && a[k] === b[k]);
}

function deepEqual(a, b, seen = new Map()) {
  if (a === b) return true;
  if (a === null || b === null || typeof a !== 'object' || typeof b !== 'object') {
    return Number.isNaN(a) && Number.isNaN(b);
  }
  if (Object.getPrototypeOf(a) !== Object.getPrototypeOf(b)) return false;
  if (seen.get(a) === b) return true;
  seen.set(a, b);
  if (Array.isArray(a)) {
    return a.length === b.length && a.every((v, i) => deepEqual(v, b[i], seen));
  }
  const ka = Object.keys(a), kb = Object.keys(b);
  return ka.length === kb.length &&
         ka.every((k) => k in b && deepEqual(a[k], b[k], seen));
}

// A Set of OBJECTS cannot use .has() -- it compares by identity.
// So you have to search, and searching is O(n^2).
function setsEqual(a, b) {
  if (a.size !== b.size) return false;
  const remaining = [...b];
  for (const value of a) {
    const i = remaining.findIndex((other) => deepEqual(value, other));
    if (i === -1) return false;
    remaining.splice(i, 1);          // consume it, so duplicates are handled
  }
  return true;
}

Step 8

Complexity, in sentences

CaseTimeSpace
equal objectsO(n)O(n) seen map + O(d) stack
differ earlyO(1) — short-circuitsO(d)
JSON.stringify comparisonO(n) always, both serialisedO(n) two strings
unordered sets of objectsO(n2)O(n)

The recursive version's advantage is short-circuiting: it returns false at the first difference and never looks at the rest. For “are these two large objects equal?” where they usually are not, that is the whole game.

The last row is the one to flag. Comparing unordered collections of objects is genuinely quadratic because there is no lookup key — you have to search for a match, and consume it so multiplicity is respected. If the elements have an id, index by it.

Say this in the interview

“Start with a === b, which covers identical references and equal primitives. If either is not an object, the only remaining true case is NaN against NaN. Then compare prototypes, so an array is never equal to an object and a Date is never compared key-by-key. Then the cycle guard — a Map from a to b, set before recursing, and if the pair is already being compared, return true. Then the built-ins: Date by getTime, RegExp by source and flags, Map and Set by size and membership. Then arrays by index, and plain objects by key count plus hasOwnProperty — both, because otherwise {a: undefined} and {b: undefined} compare equal. And JSON.stringify comparison is wrong on key order, dropped undefined, NaN, Maps and Sets, prototypes, and it throws on cycles.”

What to carry forward

“Equal” is a decision, not a fact. Is -0 equal to 0? Is a missing key equal to an undefined one? Is a Dog with the same fields equal to a Cat? Is [1,2] equal to [2,1]? Every library answers those differently, and the reason this question is asked is to see whether you know they are questions.
