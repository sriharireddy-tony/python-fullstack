Sliding window · Problem 04

Fruit Into Baskets

A story about picking fruit that is really one line of maths: find the longest window containing at most two distinct values. The main skill this page teaches is translating a word problem into the algorithm hiding inside it.

Step 1

The problem

You walk along a row of fruit trees, carrying two baskets. Each basket can only hold one type of fruit, but any amount of it. You must:

  • Start at any tree you like.
  • Pick exactly one fruit from every tree you pass, moving right.
  • Stop as soon as you reach a fruit you cannot carry.

How many fruits can you pick at most?

TreesAnswerThe stretch
[1, 2, 1]3all of it — only two types
[0, 1, 2, 2]3[1, 2, 2]
[1, 2, 3, 2, 2]4[2, 3, 2, 2]
[3,3,3,1,2,1,1,2,3,3,4]5[1,2,1,1,2]
Translating the story

“Two baskets, one type each” → at most 2 distinct values.
“Every tree you pass, moving right” → a contiguous window.
“How many fruits at most” → the longest such window.

So: longest subarray with at most two distinct values. That is the entire problem, and the fruit is decoration.

Word problems like this are common, and the skill being tested is partly whether you can strip the story away. Write the one-line restatement on the board before you write any code — it also gives the interviewer a chance to correct you early.

Step 2

Think first — try every starting tree

Version 0 — walk from every start
function totalFruitBrute(fruits) {
  let best = 0;

  for (let start = 0; start < fruits.length; start++) {
    const basket = new Set();
    let count = 0;

    for (let i = start; i < fruits.length; i++) {
      basket.add(fruits[i]);
      if (basket.size > 2) break;     // cannot carry this one -- stop
      count++;
    }

    best = Math.max(best, count);
  }

  return best;
}

console.log(totalFruitBrute([1, 2, 1]));                     // 3
console.log(totalFruitBrute([0, 1, 2, 2]));                  // 3
console.log(totalFruitBrute([1, 2, 3, 2, 2]));               // 4
console.log(totalFruitBrute([3,3,3,1,2,1,1,2,3,3,4]));       // 5
console.log(totalFruitBrute([]));                            // 0
console.log(totalFruitBrute([5]));                           // 1

This mirrors the story exactly — start at a tree, walk until you cannot carry the next fruit — which makes it easy to trust. Its cost is O(n²): every start walks forward until it hits a third type.

Step 3

Why it is slow

Each start re-walks ground the previous start already covered. Take [1,1,1,1,1,2,2,2,2,3]: starting at 0 walks nine trees, starting at 1 walks eight of the same trees, and so on.

Timing demo
// Long stretches of two types, then a third -- the worst case.
const N = 40000;
const fruits = [];
for (let i = 0; i < N; i++) fruits.push(i % 2);   // only 1s and 0s
fruits.push(9);                                   // one intruder at the end

function brute(a) {
  let best = 0;
  for (let s = 0; s < a.length; s++) {
    const basket = new Set();
    let n = 0;
    for (let i = s; i < a.length; i++) {
      basket.add(a[i]);
      if (basket.size > 2) break;
      n++;
    }
    if (n > best) best = n;
  }
  return best;
}

function windowed(a) {
  const counts = new Map();
  let left = 0, best = 0;
  for (let right = 0; right < a.length; right++) {
    counts.set(a[right], (counts.get(a[right]) || 0) + 1);
    while (counts.size > 2) {
      const n = counts.get(a[left]) - 1;
      if (n === 0) counts.delete(a[left]); else counts.set(a[left], n);
      left++;
    }
    if (right - left + 1 > best) best = right - left + 1;
  }
  return best;
}

const bruteMs = performance.now() - t;

Step 4

The better idea — the standard longest-window shape

The unlock

Grow the window on the right, adding each fruit to a count map. While the window holds more than two distinct types, drop fruit from the left. Then record the length — the window is valid again.

This is the identical skeleton to Longest Substring Without Repeating Characters and Longest Repeating Character Replacement. Only the validity test changes:

ProblemWindow is invalid when…
Longest substring without repeatsa character appears twice
Longest repeating char replacementlength - maxCount > k
Fruit into basketscounts.size > 2
At most K distinctcounts.size > k

The line that keeps counts.size honest

The whole validity test is counts.size, so the map must contain exactly the types currently in the window — no more. When a count drops to zero, that type is gone and its entry must be deleted, not left sitting at zero.

the delete that makes it work
const n = counts.get(fruits[left]) - 1;
if (n === 0) counts.delete(fruits[left]);   // gone from the window
else counts.set(fruits[left], n);
left++;

Leave a zero entry behind and counts.size keeps counting a type that is no longer there. The window then shrinks forever and the answer is far too small — or the loop never terminates.

Four drops in one step at right=8, and that is fine — the while loop only ever moves left forward, and across the whole run it can move at most n times in total. That is the O(n) argument.

the algorithm, narrating itself
function fruitExplained(fruits) {
  const counts = new Map();
  let left = 0, best = 0;

  console.log('fruits =', fruits);
  console.log('');

  for (let right = 0; right < fruits.length; right++) {
    const f = fruits[right];
    counts.set(f, (counts.get(f) || 0) + 1);
    console.log('right=' + right + '  pick ' + f + '   counts ' +
                JSON.stringify([...counts]) + '   size ' + counts.size);

    while (counts.size > 2) {
      const gone = fruits[left];
      const n = counts.get(gone) - 1;
      if (n === 0) {
        counts.delete(gone);
        console.log('        too many types -> drop ' + gone +
                    ' (last one, DELETED)   size ' + counts.size);
      } else {
        counts.set(gone, n);
        console.log('        too many types -> drop one ' + gone +
                    ' (still ' + n + ' left)   size ' + counts.size);
      }
      left++;
    }

    const len = right - left + 1;
    const improved = len > best;
    if (improved) best = len;

    console.log('        window [' + fruits.slice(left, right + 1).join(',') +
                ']  length ' + len + '   best=' + best +
                (improved ? '   *new best*' : ''));
  }

  console.log('');
  return best;
}

Step 6

Version 1 — without built-in methods

Version 1 — plain object, manual distinct count
function totalFruitManual(fruits) {
  const counts = {};      // type -> how many in the window
  let distinct = 0;       // how many types the window holds
  let left = 0;
  let best = 0;

  for (let right = 0; right < fruits.length; right++) {
    const f = fruits[right];

    if (counts[f] === undefined || counts[f] === 0) {
      counts[f] = 0;
      distinct = distinct + 1;      // a new type just arrived
    }
    counts[f] = counts[f] + 1;

    // too many types? drop from the left until we are back to two
    while (distinct > 2) {
      const gone = fruits[left];
      counts[gone] = counts[gone] - 1;

      if (counts[gone] === 0) {
        distinct = distinct - 1;    // that type has left entirely
      }

      left = left + 1;
    }

    const length = right - left + 1;
    if (length > best) best = length;
  }

  return best;
}

console.log(totalFruitManual([1, 2, 1]));                   // 3
console.log(totalFruitManual([0, 1, 2, 2]));                // 3
console.log(totalFruitManual([1, 2, 3, 2, 2]));             // 4
console.log(totalFruitManual([3,3,3,1,2,1,1,2,3,3,4]));     // 5
console.log(totalFruitManual([]));                          // 0
console.log(totalFruitManual([5]));                         // 1
console.log(totalFruitManual([1,1,1,1]));                   // 4
console.log(totalFruitManual([1,2,3,4,5]));                 // 2

Tracking distinct by hand instead of relying on counts.size makes the two transitions explicit: it goes up when a count moves from 0 to 1, and down when it moves from 1 to 0. That is the same incremental-invariant idea as formed and matches on the previous pages.

variation — report which trees, and which fruits
function bestHarvest(fruits) {
  const counts = new Map();
  let left = 0, best = 0, bestStart = 0;

  for (let right = 0; right < fruits.length; right++) {
    counts.set(fruits[right], (counts.get(fruits[right]) || 0) + 1);

    while (counts.size > 2) {
      const n = counts.get(fruits[left]) - 1;
      if (n === 0) counts.delete(fruits[left]); else counts.set(fruits[left], n);
      left++;
    }

    if (right - left + 1 > best) {
      best = right - left + 1;
      bestStart = left;                 // freeze only on a new best
    }
  }

  const picked = fruits.slice(bestStart, bestStart + best);
  return { total: best, from: bestStart, to: bestStart + best - 1,
           picked, baskets: [...new Set(picked)] };
}

console.log(bestHarvest([1, 2, 3, 2, 2]));
// { total: 4, from: 1, to: 4, picked: [2,3,2,2], baskets: [2,3] }

console.log(bestHarvest([3,3,3,1,2,1,1,2,3,3,4]));
// { total: 5, from: 3, to: 7, picked: [1,2,1,1,2], baskets: [1,2] }

console.log(bestHarvest([1,2,3,4,5]));
Step 7

Version 2 — with built-in methods

Version 2 — the interview answer
function totalFruit(fruits) {
  const counts = new Map();
  let left = 0;
  let best = 0;

  for (let right = 0; right < fruits.length; right++) {
    counts.set(fruits[right], (counts.get(fruits[right]) || 0) + 1);

    while (counts.size > 2) {
      const gone = fruits[left];
      const n = counts.get(gone) - 1;
      if (n === 0) counts.delete(gone);
      else counts.set(gone, n);
      left++;
    }

    best = Math.max(best, right - left + 1);
  }

  return best;
}

the general version — at most K distinct
// Fruit Into Baskets is this with k = 2. Writing the general one
// costs nothing and covers three problems at once.
function longestWithAtMostKDistinct(items, k) {
  if (k <= 0) return 0;

  const counts = new Map();
  let left = 0, best = 0;

  for (let right = 0; right < items.length; right++) {
    counts.set(items[right], (counts.get(items[right]) || 0) + 1);

    while (counts.size > k) {
      const gone = items[left];
      const n = counts.get(gone) - 1;
      if (n === 0) counts.delete(gone); else counts.set(gone, n);
      left++;
    }

    best = Math.max(best, right - left + 1);
  }

  return best;
}

console.log(longestWithAtMostKDistinct([1,2,3,2,2], 2));        // 4  -- fruit baskets
console.log(longestWithAtMostKDistinct([...'eceba'], 2));       // 3  -- "ece"
console.log(longestWithAtMostKDistinct([...'aa'], 1));          // 2
console.log(longestWithAtMostKDistinct([...'abcadcacacaca'], 3));// 11
console.log(longestWithAtMostKDistinct([1,2,3,4,5], 1));        // 1
console.log(longestWithAtMostKDistinct([1,2,3,4,5], 0));        // 0

// Three named problems, one function:
//   k = 2  -> Fruit Into Baskets
//   k = 2  -> Longest Substring with At Most Two Distinct Characters
//   k = k  -> Longest Substring with At Most K Distinct Characters
the O(1)-space version, since k is 2
// With exactly two baskets you do not need a map at all -- two
// variables will do. Faster, and much easier to get subtly wrong.
function totalFruitTwoVars(fruits) {
  if (fruits.length === 0) return 0;

  let lastType = fruits[0];       // the most recently seen type
  let otherType = -1;             // the other basket, -1 = empty
  let lastTypeRun = 1;            // how long the trailing run of lastType is
  let current = 1;                // the current window length
  let best = 1;

  for (let i = 1; i < fruits.length; i++) {
    const f = fruits[i];

    if (f === lastType || f === otherType) {
      current++;
    } else {
      // a third type: restart from the trailing run plus this fruit
      current = lastTypeRun + 1;
      otherType = lastType;
    }

    if (f === lastType) {
      lastTypeRun++;
    } else {
      lastTypeRun = 1;
      lastType = f;
    }

    best = Math.max(best, current);
  }

  return best;
}

console.log(totalFruitTwoVars([1, 2, 1]));                 // 3
console.log(totalFruitTwoVars([0, 1, 2, 2]));              // 3
console.log(totalFruitTwoVars([1, 2, 3, 2, 2]));           // 4
console.log(totalFruitTwoVars([3,3,3,1,2,1,1,2,3,3,4]));   // 5
console.log(totalFruitTwoVars([5]));                       // 1
console.log(totalFruitTwoVars([1,2,3,4,5]));               // 2

// O(1) space instead of O(k). Correct, and notice how much harder
// it is to convince yourself of. That is the trade: the map version
// generalises AND is obviously right. Ship the map version.
Step 8

Complexity, in sentences

SolutionTimeSpace
Walk from every startO(n²)O(1)
Sliding window with a mapO(n)O(k) = O(1)
Two variablesO(n)O(1)

Why the inner while does not make it quadratic. It only advances left, and left travels from 0 to n exactly once across the entire run — it never resets. So the two pointers together take at most 2n steps, however unevenly those steps are distributed. One step can drop four fruits, as the Step 5 trace shows; that budget is taken out of the same total.

Space is O(k), and here k is 3 at most — the map briefly holds three types before shrinking. So effectively O(1).

Say this in the interview

“Stripping the story: this is the longest subarray with at most two distinct values. I slide a window with a map from value to count, extending right and, while the map holds more than two keys, dropping from the left — deleting a key when its count reaches zero, so map.size stays accurate. I record the length after each shrink. Both pointers only move forward, so O(n) time and O(1) space for a fixed limit of two. The same code with k instead of 2 solves at-most-K-distinct.”

Step 9

Mistakes people actually make

1. Not deleting the key when the count hits zero

Broken — size never comes back down
function broken(fruits) {
  const counts = new Map();
  let left = 0, best = 0;

  for (let right = 0; right < fruits.length; right++) {
    counts.set(fruits[right], (counts.get(fruits[right]) || 0) + 1);

    while (counts.size > 2 && left <= right) {
      counts.set(fruits[left], counts.get(fruits[left]) - 1);   // never deleted
      left++;
    }

    best = Math.max(best, right - left + 1);
  }

  return best;
}

console.log(broken([1, 2, 1]));               // 3   fine, only two types
console.log(broken([1, 2, 3, 2, 2]));         // 2   WRONG, should be 4
console.log(broken([0, 1, 2, 2]));            // 2   WRONG, should be 3
console.log(broken([1, 1, 2, 3, 2, 2]));      // 3   WRONG, should be 4

// Once a third type appears, its key stays in the map at zero, so
// counts.size is permanently 3 and the window is shrunk to nothing
// on every step. (The `left <= right` guard is the only thing
// stopping an infinite loop.)

2. Using a Set instead of a Map

Broken — no way to know when a type leaves
function broken(fruits) {
  const basket = new Set();
  let left = 0, best = 0;

  for (let right = 0; right < fruits.length; right++) {
    basket.add(fruits[right]);

    while (basket.size > 2) {
      basket.delete(fruits[left]);    // deletes even if more remain in the window
      left++;
    }

    best = Math.max(best, right - left + 1);
  }
  return best;
}

console.log(broken([1, 2, 1]));                 // 3   fine
console.log(broken([1, 2, 3, 2, 2]));           // 4   right, by luck
console.log(broken([1, 1, 2, 3, 2, 2]));        // 5   WRONG, should be 4
console.log(broken([1, 2, 2, 3, 2, 2, 1]));     // 5   right, by luck
console.log(broken([3, 3, 1, 3, 2, 3, 3]));     // 4   right, by luck

// A Set only knows PRESENCE. On [1,1,2,3,2,2] the window grows to
// include the 3, the Set deletes type 1 from the left -- but there
// is still another 1 inside the window. The Set now claims two
// types when the window really holds three, and it reports a
// window of 5 that could never be picked.
// You need COUNTS to know when the LAST copy of a type has left.

3. Recording the length before shrinking

Broken — measures an invalid window
function broken(fruits) {
  const counts = new Map();
  let left = 0, best = 0;

  for (let right = 0; right < fruits.length; right++) {
    counts.set(fruits[right], (counts.get(fruits[right]) || 0) + 1);

    best = Math.max(best, right - left + 1);      // recorded BEFORE shrinking

    while (counts.size > 2) {
      const n = counts.get(fruits[left]) - 1;
      if (n === 0) counts.delete(fruits[left]); else counts.set(fruits[left], n);
      left++;
    }
  }
  return best;
}

4. Hard-coding two baskets when the follow-up asks for K

The two-variable version in Step 7 is fast and completely unextendable. Interviewers routinely follow up with “now make it K baskets”, and rewriting from scratch under pressure is worse than having written the map version in the first place. Write the general shape; mention the specialised one as an optimisation.

5. Misreading the story

“Two baskets, one type of fruit each” means at most two distinct types — not two fruits, and not two of each. Read the constraint back in your own words before coding. If you had written “at most 2 fruits per basket”, every answer would be 4.

Step 10

Practice before you move on

  1. State the one-line restatement first, then write the general at-most-K version from memory. Two baskets is a call with k = 2.
  2. Longest Substring with At Most K Distinct Characters. Literally the same function on characters. Confirm your general version handles it unchanged.
  3. Return the trees you picked from, not just the count. In Step 6 — and remember to freeze the start only on a new best.
  4. Exactly K distinct, not at most. A neat trick: exactly(k) equals atMost(k) - atMost(k - 1). Work out why that is true — it is a genuinely useful counting identity.
  5. Longest window with at most K distinct, where you may also skip one tree. Invent your own variation and see whether the skeleton still fits. Most of the time it does, which is the point.
What to carry forward

Strip the story before you solve it. Fruit and baskets, rooms and meetings, tasks and cooldowns — the narrative is nearly always a costume over a standard shape. Write the one-line restatement first: it forces you to identify the real constraint, it catches misreadings early, and it usually names the technique for you. Here, “longest window with at most two distinct values” is both the restatement and the algorithm.
