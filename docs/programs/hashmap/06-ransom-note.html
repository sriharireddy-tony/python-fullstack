Hash map · Problem 06

Ransom Note & Character Counting

The simplest problem in this collection, and the one whose technique you will use most often. This page is really about the frequency map itself — how to build one, how to spend one, and the four small ways people get it wrong.

Step 1

The problem

You have a magazine and want to cut out letters to spell a ransom note. Each letter in the magazine can be used at most once. Can you build the note?

NoteMagazineAnswerWhy
"a""b"falseno a available
"aa""ab"falseonly one a
"aa""aab"truetwo a’s, one spare b
"""anything"truean empty note needs nothing
"abc"""false
How this differs from Valid Anagram

Valid Anagram: the two strings must use exactly the same letters, so the lengths must match and the budget must land on zero.

Ransom Note: the magazine may have spare letters. So there is no length check, and leftover budget is fine. It is the same build-and-spend, minus one condition.

Row two is the row that matters. "aa" needs two a’s. Any solution based on “does the magazine contain this character?” passes it and is wrong.

Step 2

Think first — the two obvious answers

Version 0a — the one-liner that is wrong
function tempting(note, magazine) {
  for (const ch of note) {
    if (!magazine.includes(ch)) return false;
  }
  return true;
}

console.log(tempting('a', 'b'));       // false   correct
console.log(tempting('abc', ''));      // false   correct
console.log(tempting('aa', 'aab'));    // true    correct
console.log(tempting('aa', 'ab'));     // TRUE    WRONG, should be false

// `includes` answers "is there at least one?" -- it never runs out.
// The note needs two a's; the magazine has one; the check passes
// twice because it never consumes anything.
Version 0b — consume as you go
function byRemoving(note, magazine) {
  let remaining = magazine;

  for (const ch of note) {
    const at = remaining.indexOf(ch);
    if (at === -1) return false;                      // ran out
    remaining = remaining.slice(0, at) + remaining.slice(at + 1);   // cut it out
  }

  return true;
}

console.log(byRemoving('a', 'b'));       // false
console.log(byRemoving('aa', 'ab'));     // false   correct now
console.log(byRemoving('aa', 'aab'));    // true
console.log(byRemoving('', 'anything')); // true

// Correct -- it literally cuts each letter out of the magazine.
// And it rebuilds the whole magazine string on every letter, so it
// is O(note x magazine).
Step 3

Why it is slow

Both includes and indexOf scan the magazine, and the removing version also allocates a fresh string each time. With a note of length m and a magazine of length n that is O(m × n).

Timing demo
// The letters the note needs are all at the END of the magazine,
// so every indexOf has to scan past the whole first half.
const M = 2000;                                  // note length
const N = 20000;                                 // filler length

const note = 'z'.repeat(M);
const magazine = 'a'.repeat(N) + 'z'.repeat(M);

function scanning(n, m) {
  let rest = m;
  for (const ch of n) {
    const at = rest.indexOf(ch);
    if (at === -1) return false;
    rest = rest.slice(0, at) + rest.slice(at + 1);
  }
  return true;
}

function counting(n, m) {
  const budget = new Map();
  for (const ch of m) budget.set(ch, (budget.get(ch) || 0) + 1);
  for (const ch of n) {
    const left = budget.get(ch);
    if (!left) return false;
    budget.set(ch, left - 1);
  }
  return true;
}

let t = performance.now();
const a = scanning(note, magazine);
const scanMs = performance.now() - t;

t = performance.now();
const b = counting(note, magazine);
const countMs = performance.now() - t;

console.log('scan and cut out :', a, 'in', scanMs.toFixed(1) + ' ms');
console.log('count and spend  :', b, 'in', countMs.toFixed(2) + ' ms');
console.log('same answer:', a === b);
console.log('speed-up:', Math.round(scanMs / Math.max(countMs, 0.01)) + 'x');
Step 4

The better idea — count once, then spend

The unlock

Pass 1: count every character of the magazine into a map. That is your budget.
Pass 2: walk the note, decrementing. If a character is missing or the count has already reached zero, you cannot afford the note.

The magazine is scanned once instead of once per letter of the note. Each lookup is constant time. Total: O(m + n).

  note = "aa"    magazine = "aab"

  PASS 1 -- the budget
    a -> {a:1}
    a -> {a:2}
    b -> {a:2, b:1}

  PASS 2 -- spend it
    'a'  budget has 2  ->  spend, now 1
    'a'  budget has 1  ->  spend, now 0

  never overdrawn -> TRUE
  (the leftover b is fine -- spare letters are allowed)


  note = "aa"    magazine = "ab"

  PASS 1 -- budget {a:1, b:1}

  PASS 2
    'a'  budget has 1  ->  spend, now 0
    'a'  budget has 0  ->  OVERDRAWN  ->  FALSE

Which string gets counted

Count the magazine, spend the note. Getting it backwards produces a subtly different question — “can the note supply the magazine?” — which is the wrong way round and gives wrong answers whenever the magazine has spare letters.

A cheap early exit

If the note is longer than the magazine, it is impossible — return false immediately. One line, and it short-circuits a large class of negative cases before any counting happens.

the algorithm, narrating itself
function canBuildExplained(note, magazine) {
  console.log('note = "' + note + '"   magazine = "' + magazine + '"');

  if (note.length > magazine.length) {
    console.log('note is longer than the magazine -> FALSE');
    console.log('');
    return false;
  }

  const budget = new Map();

  console.log('PASS 1 -- count the magazine');
  for (const ch of magazine) {
    budget.set(ch, (budget.get(ch) || 0) + 1);
    console.log("  '" + ch + "'  ->  " + JSON.stringify([...budget]));
  }

  console.log('PASS 2 -- spend it with the note');
  for (const ch of note) {
    const left = budget.get(ch) || 0;

    if (left === 0) {
      console.log("  '" + ch + "'  budget has 0  ->  OVERDRAWN, FALSE");
      console.log('');
      return false;
    }

    budget.set(ch, left - 1);
    console.log("  '" + ch + "'  had " + left + ", spend one  ->  " +
                JSON.stringify([...budget]));
  }

  console.log('never overdrawn -> TRUE');
  console.log('');
  return true;
}

console.log('ANSWER:', canBuildExplained('aabb', 'aabbcc'));
console.log('==========================================');
console.log('ANSWER:', canBuildExplained('aa', 'ab'));
Step 6

Version 1 — without built-in methods

Version 1 — a 26-slot counter array
function canConstructManual(note, magazine) {
  if (note.length > magazine.length) return false;

  const counts = [];
  for (let i = 0; i < 26; i++) counts[i] = 0;

  // PASS 1: the magazine is the budget
  for (let i = 0; i < magazine.length; i++) {
    const idx = magazine.charCodeAt(i) - 97;
    counts[idx] = counts[idx] + 1;
  }

  // PASS 2: the note spends it
  for (let i = 0; i < note.length; i++) {
    const idx = note.charCodeAt(i) - 97;

    if (counts[idx] === 0) return false;    // ran out of this letter

    counts[idx] = counts[idx] - 1;
  }

  return true;
}

console.log(canConstructManual('a', 'b'));           // false
console.log(canConstructManual('aa', 'ab'));         // false
console.log(canConstructManual('aa', 'aab'));        // true
console.log(canConstructManual('', 'anything'));     // true
console.log(canConstructManual('abc', ''));          // false
console.log(canConstructManual('abc', 'cba'));       // true
console.log(canConstructManual('aabbcc', 'abcabc')); // true
console.log(canConstructManual('', ''));             // true
the frequency map, as a reusable helper
// This is the function you will write again and again. Worth being
// able to produce it without thinking.
function countBy(items, keyOf = x => x) {
  const counts = new Map();
  for (const item of items) {
    const key = keyOf(item);
    counts.set(key, (counts.get(key) || 0) + 1);
  }
  return counts;
}

console.log(countBy('hello'));                          // h,e,l x2,o
console.log(countBy([1, 2, 2, 3, 3, 3]));               // 1,2x2,3x3
console.log(countBy(['apple', 'avocado', 'banana'], w => w[0]));   // a x2, b
console.log(countBy([1,2,3,4,5,6], n => n % 2 ? 'odd' : 'even'));  // odd x3, even x3

// Everything on this page, and half of the string problems in this
// collection, is countBy plus one loop.
function canConstruct(note, magazine) {
  const budget = countBy(magazine);
  for (const ch of note) {
    const left = budget.get(ch);
    if (!left) return false;
    budget.set(ch, left - 1);
  }
  return true;
}

console.log('');
console.log(canConstruct('aa', 'aab'));   // true
console.log(canConstruct('aa', 'ab'));    // false
Step 7

Version 2 — with built-in methods

Version 2 — the interview answer
function canConstruct(note, magazine) {
  if (note.length > magazine.length) return false;

  const budget = new Map();
  for (const ch of magazine) budget.set(ch, (budget.get(ch) || 0) + 1);

  for (const ch of note) {
    const left = budget.get(ch);
    if (!left) return false;          // undefined or 0, both mean "cannot afford"
    budget.set(ch, left - 1);
  }

  return true;
}

console.log(canConstruct('a', 'b'));            // false
console.log(canConstruct('aa', 'ab'));          // false
console.log(canConstruct('aa', 'aab'));         // true
console.log(canConstruct('', 'anything'));      // true
console.log(canConstruct('Hi!', '!Hi there'));  // true  -- any characters
console.log(canConstruct('a b', 'b a'));        // true  -- spaces count
the family of questions one frequency map answers
const countBy = (items) => {
  const m = new Map();
  for (const x of items) m.set(x, (m.get(x) || 0) + 1);
  return m;
};

const text = 'the quick brown fox jumps over the lazy dog the end';

// 1. word frequencies
const words = countBy(text.split(' '));
console.log('word counts:', [...words].filter(([, n]) => n > 1));

// 2. the most common item
function mostCommon(items) {
  let best = null, bestCount = 0;
  for (const [k, n] of countBy(items)) if (n > bestCount) { best = k; bestCount = n; }
  return { value: best, count: bestCount };
}
console.log('most common word:', mostCommon(text.split(' ')));

// 3. anything appearing exactly once
const letters = countBy([...text.replace(/ /g, '')]);
console.log('letters used once:', [...letters].filter(([, n]) => n === 1).map(([c]) => c));

// 4. do two collections have the same contents?
function sameContents(a, b) {
  const ca = countBy(a), cb = countBy(b);
  if (ca.size !== cb.size) return false;
  for (const [k, n] of ca) if (cb.get(k) !== n) return false;
  return true;
}
console.log('same contents:', sameContents('listen', 'silent'));   // true
console.log('same contents:', sameContents('aabb', 'abbb'));       // false

// 5. can a be built from b? (this page)
function canBuild(a, b) {
  const budget = countBy(b);
  for (const x of a) {
    const left = budget.get(x);
    if (!left) return false;
    budget.set(x, left - 1);
  }
  return true;
}
console.log('canBuild:', canBuild('cat', 'tactful'));   // true
console.log('canBuild:', canBuild('cattt', 'tactful')); // false
counting things that are not characters
// The technique does not care what it counts, as long as the key
// is something a Map can hold.
const orders = [
  { id: 1, status: 'shipped',  region: 'north' },
  { id: 2, status: 'pending',  region: 'south' },
  { id: 3, status: 'shipped',  region: 'north' },
  { id: 4, status: 'cancelled',region: 'north' },
  { id: 5, status: 'shipped',  region: 'south' }
];

function countByKey(items, keyOf) {
  const m = new Map();
  for (const item of items) {
    const k = keyOf(item);
    m.set(k, (m.get(k) || 0) + 1);
  }
  return m;
}

console.log('by status:', [...countByKey(orders, o => o.status)]);
console.log('by region:', [...countByKey(orders, o => o.region)]);
console.log('by both  :', [...countByKey(orders, o => o.region + '/' + o.status)]);

// That last one -- a composite key built by joining fields -- is how
// you count by more than one dimension without nesting maps. Pick a
// separator that cannot appear in the values.
Step 8

Complexity, in sentences

SolutionTimeSpaceCorrect?
includes per characterO(m · n)O(1)no
Cut letters outO(m · n)O(n)yes
Count then spendO(m + n)O(k)yes

m is the note length, n the magazine length, k the number of distinct characters.

One pass over each string, and every map operation is constant time. Sequential passes add: m + n, which is O(m + n) — linear in the total input.

Space is O(k), bounded by the alphabet. For lowercase letters that is 26 counters no matter how long the magazine is — effectively O(1).

Say this in the interview

“includes per character is O(m·n) and, worse, it never consumes a letter — so "aa" passes against a magazine with one a. I count the magazine into a frequency map once, then walk the note decrementing, returning false if a count is missing or already zero. O(m + n) time, O(k) space. Unlike Valid Anagram there is no length equality and no final zero check, because spare letters are allowed.”

Step 9

Mistakes people actually make

1. Using includes or a Set

Shown in Step 2. Both answer “is it present?” when the question is “how many?”. "aa" against "ab" is the test case that exposes it, and it is the first thing an interviewer will try.

2. Counting the note instead of the magazine

Broken — backwards
function broken(note, magazine) {
  const budget = new Map();
  for (const ch of note) budget.set(ch, (budget.get(ch) || 0) + 1);   // counted the NOTE
  for (const ch of magazine) {
    const left = budget.get(ch);
    if (!left) return false;
    budget.set(ch, left - 1);
  }
  return true;
}

console.log(broken('aa', 'aab'));        // false  WRONG, should be true
console.log(broken('abc', 'cba'));       // true   right, by luck
console.log(broken('a', 'aaaa'));        // false  WRONG, should be true

// It asks "can the NOTE supply the MAGAZINE?", which fails the
// moment the magazine has anything spare -- and having spare
// letters is the normal case.

3. Adding a length-equality check

Broken — Valid Anagram's rule, wrong problem
function broken(note, magazine) {
  if (note.length !== magazine.length) return false;   // copied from anagrams -- bug
  const budget = new Map();
  for (const ch of magazine) budget.set(ch, (budget.get(ch) || 0) + 1);
  for (const ch of note) {
    const left = budget.get(ch);
    if (!left) return false;
    budget.set(ch, left - 1);
  }
  return true;
}

console.log(broken('abc', 'cba'));        // true   fine
console.log(broken('aa', 'aab'));         // false  WRONG, should be true
console.log(broken('', 'anything'));      // false  WRONG, should be true

// The magazine is allowed to be bigger. The correct guard is
// note.length > magazine.length, and it is an optimisation, not a
// requirement.

4. Not decrementing at all

Broken — checks but never spends
function broken(note, magazine) {
  const budget = new Map();
  for (const ch of magazine) budget.set(ch, (budget.get(ch) || 0) + 1);
  for (const ch of note) {
    if (!budget.has(ch)) return false;     // checks presence, never spends
  }
  return true;
}

console.log(broken('aa', 'ab'));     // TRUE   WRONG, should be false
console.log(broken('aaa', 'a'));     // TRUE   WRONG, should be false

// Building the counts and then not using them is the same bug as
// `includes`, with extra steps. The DECREMENT is the whole point.

5. Using if (budget[ch]) with a 26-slot array

Falsy checks are safe here only because 0 and undefined both mean “cannot afford”. That is a happy coincidence, not a rule. In the general countBy helper, where a stored value could legitimately be 0 or an empty string, use has() instead. The habit that always works: ask whether the key exists, then compare the value explicitly.

Step 10

Practice before you move on

  1. Write countBy from memory. It is four lines and you will use it in a dozen other problems. Then build this page’s answer on top of it.
  2. Return what is missing, not just true or false. “You need two more a’s and one z” is far more useful, and it is a small change: keep going instead of returning early, and collect the shortfalls.
  3. Case-insensitive, ignoring spaces and punctuation. Normalise both strings first — the same clean helper from Valid Anagram.
  4. Word-level ransom note. Can you build a sentence from a bag of words? Split on whitespace and count words instead of characters. The algorithm does not change at all.
  5. How many complete copies of the note can you make? For each character, divide the magazine count by the note count, and take the minimum. Two lines with two frequency maps.
What to carry forward

The frequency map is the workhorse of this entire subject. Build one, then do exactly one of four things with it: compare two of them (anagrams), spend one down (this page), scan for a particular count (first unique), or slide a window and keep one in sync (permutation in string). Almost every counting problem is one of those four, and recognising which saves you from deriving the same idea from scratch each time.
